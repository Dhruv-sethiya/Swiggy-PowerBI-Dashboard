# Swiggy Power BI Dashboard

An interactive Power BI dashboard built to analyze Swiggy order data, revenue performance, customer behavior, payment methods, cuisine preferences, delivery performance, and customer ratings.

## 📊 Project Overview

This project transforms a large Swiggy order dataset into an interactive executive dashboard using Microsoft Power BI.

The dashboard provides a centralized view of:

- Sales and revenue performance
- Order volume
- Customer behavior
- Cuisine preferences
- Payment methods
- Delivery performance
- Customer ratings
- Monthly revenue trends

## 🎯 Business Objectives

The main objectives of this project are to:

1. Track overall order and revenue performance.
2. Identify cities contributing the most revenue.
3. Analyze cuisine-wise order demand.
4. Understand customer payment preferences.
5. Monitor delivery-time performance.
6. Evaluate customer satisfaction through ratings.
7. Analyze monthly revenue trends.
8. Provide interactive filtering for business analysis.
